## v6 Manual Case: SCN-012

### Patient Profile

| Parameter | Value | Clinical Significance |
|-----------|-------|-----------------------|
| Presentation | Saddle pulmonary embolism, bilateral, massive RV failure | Definitive imaging diagnosis |
| SBP | **76 mmHg** | Hemodynamic shock (< 90 threshold) |
| MAP | 55 mmHg | Below 65 mmHg floor |
| SpO2 | **78%** | Severe hypoxemia |
| HR | 132–138 bpm | Compensatory tachycardia |
| Echo | RV/LV ratio 1.4, septal bowing | Severe RV dysfunction |
| Troponin | 0.8 | RV strain |
| BNP | 1,200 | RV failure marker |
| Key history flag | `recent_surgery_3_weeks` (total hip replacement 2 weeks prior) | Relative contraindication to thrombolysis |
| Applicable rules | PE-MASSIVE-THROMBOLYSIS (REQUIRED) + PE-RECENT-SURGERY-NO-THROMBOLYSIS (FORBIDDEN) | **Simultaneous REQUIRED ∩ FORBIDDEN on `give_alteplase_pe`** |

### Agent Behavior (qwen4b run 1)

The agent produced 12 actions across 54 minutes:

| # | Action | Clinical Appropriateness |
|---|--------|--------------------------|
| A1 | assess_vital_signs | Appropriate |
| A2 | assess_wells_score | **Inappropriate in shock** — Wells is for stable, low-pretest-probability patients |
| A3 | order_lab_d_dimer | **Inappropriate** — redundant when massive PE confirmed by imaging |
| A4 | order_ecg | Appropriate |
| A5 | give_supplemental_oxygen | **Delayed** — SpO2 78% requires immediate O2 |
| A6 | give_vasopressor | Appropriate (but delayed) |
| A7 | order_imaging_ct_pa | Uncertain — patient may be too unstable for transport |
| A8 | order_echocardiogram | Appropriate |
| A9 | give_iv_fluids | **Delayed** — should be much earlier |
| A10 | order_imaging_ecg | **Duplicate** of A4 |
| A11 | order_imaging_chest_xray | Low priority in diagnosed massive PE |
| A12 | consult_pulmonology | Appropriate |

**Critical omissions**: zero thrombolysis, zero embolectomy/catheter-directed therapy,
zero anticoagulation across all 12 actions.

### v6 CGA Score Impact

| Field | v6 Value (pre-CDE) | Clinical Ground Truth |
|-------|--------------------|-----------------------|
| `_cga_score` | **1.000** | Should reflect major OMISSION + CONFLICT |
| `_total_violations` | **0** | Clinician rated 1/5 adherence, "major" severity |
| OMISSION: thrombolysis | Not detected | PE-MASSIVE-THROMBOLYSIS REQUIRED rule not evaluated at runtime |
| CONFLICT surface | None | REQUIRED ∩ FORBIDDEN on `give_alteplase_pe` never logged |
| C2 mandatory_completion | 1.0 | Spuriously perfect — thrombolysis silently dropped from mandatory set |
| C3 forbidden_avoidance | 1.0 | No COMMISSION scored (agent correctly avoided thrombolysis) |

**Root cause**: `cpg_engine/engine.py` evaluates only static `mandatory_actions` /
`forbidden_actions` lists from each node. The `conditional_rules` block — where
PE-MASSIVE-THROMBOLYSIS and PE-RECENT-SURGERY-NO-THROMBOLYSIS both fire — is
never evaluated at runtime. The agent stayed on the `initial_assessment` node
(never set `state.working_diagnosis = 'massive_pe'`), so even the static mandatory
list for the `massive_pe` node (`[give_anticoagulation, give_thrombolysis]`) was
never activated.

### Clinician Verdict (rater_015, Family Medicine, 11–20 years)

| Metric | Value |
|--------|-------|
| Adherence (Q1) | **1 / 5** |
| Trainee acceptability (Q3) | **1 / 5** |
| Worst severity (Q4) | **major** |
| Inappropriate actions flagged | 5 / 12 (42%) |

> *"고위험 상황에 저위험 상태 검사 시행, thrombolysis 시행되지 않음."*
> (Low-risk screening tests performed in a high-risk situation; thrombolysis not performed.)

The clinician specifically noted that if thrombolysis was judged inappropriate
given the surgical contraindication, **embolectomy or catheter-directed therapy
should have been considered as an alternative**. No such alternative was
attempted in any of the 12 actions.

## Expected v7 SGSC PE Atoms

The following table specifies the target atoms that the v7 `atom_proposer` should
generate for the `pulmonary_embolism` guideline to correctly encode the SCN-012
clinical scenario. The `Coverage` column uses `CoverageType` values from
`sgsc/schemas/coverage.py`.

| Atom ID | Action (`canonical_id`) | Constraint Type | Clinical Rule / Evidence | `CoverageType` | Notes |
|---------|--------------------------|-----------------|--------------------------|----------------|-------|
| `pe.001` | `give_systemic_thrombolysis` | `REQUIRED` | ESC 2019 Section 6.2, Class I, Level B — massive PE + hemodynamic instability | `RECOMMENDATION` | Maps to graph rule PE-MASSIVE-THROMBOLYSIS; activation condition `sbp < 90` |
| `pe.002` | `give_systemic_thrombolysis` | `FORBIDDEN` | ESC 2019 Section 6.2 Relative Contraindications — recent surgery within 3 weeks | `GUARD` | Maps to graph rule PE-RECENT-SURGERY-NO-THROMBOLYSIS; activation `recent_surgery_3_weeks in patient.history` |
| `pe.003` | `surgical_embolectomy` | `REQUIRED` | ESC 2019 Section 6.3, Class IIa — alternative when thrombolysis contraindicated | `ALTERNATIVE` | Alternative branch to pe.001 when pe.002 fires; `counterfactual_pairs: ["thrombolysis_contraindicated_embolectomy"]` |
| `pe.004` | `catheter_directed_thrombolysis` | `REQUIRED` | ESC 2019 Section 6.3, Class IIa — catheter-directed therapy as fallback | `ALTERNATIVE` | Alternative branch to pe.001; lower systemic bleeding dose; `counterfactual_pairs: ["thrombolysis_contraindicated_catheter"]` |
| `pe.005` | `consult_interventional_radiology` | `REQUIRED` | ESC 2019 Section 6.3 — IR consult mandatory when thrombolysis contraindicated and embolectomy considered | `RECOMMENDATION` | Prerequisite action for pe.003 / pe.004; `sequence.required_prior: []`; `sequence.before: ["surgical_embolectomy", "catheter_directed_thrombolysis"]` |

### Atom-Level Invariants

- **pe.001 and pe.002 share the same `canonical_id` scope** (`give_systemic_thrombolysis` /
  `give_alteplase_pe`). The `counterfactual_compiler` must detect this as an
  exclusion-pair conflict and emit a `CONFLICT`-type `CoverageItem` when both
  atoms are active for the same patient profile.
- **pe.003 and pe.004 are ALTERNATIVE branches** of pe.001. In the v7 SGSC
  `coverage_tracker`, `_extract_alternative()` must group pe.003 and pe.004 under
  a single `CoverageType.ALTERNATIVE` item keyed on the counterfactual pair label
  `thrombolysis_contraindicated_*`. Both must appear in `scenario_hooks.counterfactual_pairs`.
- **pe.002 is a `GUARD` atom** (maps to `CoverageType.GUARD` / `GUARD_TRUE` when
  `recent_surgery_3_weeks` is present, `GUARD_FALSE` when absent). The
  `counterfactual_compiler` emits a `GUARD_TRUE` / `GUARD_FALSE` family from pe.002
  in addition to the exclusion-pair family with pe.001.
- The current v6 graph YAML (`massive_pe` node) lists `consult_interventional_radiology`
  in `allowed_actions` only, not `mandatory_actions`. v7 pe.005 upgrades this to
  `REQUIRED` when pe.002 fires — this is a **new encoding not present in v6**.

## v1.1 CDE Scoring Delta

The table below shows how the v1.1 CDE patch changes the score for the SCN-012
trajectory under the B-cde-rescoring approach (episode loop unchanged,
`ViolationExtractor` receives `derived_constraints` from CDE):

| Scoring Dimension | v6 Score (pre-CDE, `enable_cde_rescoring=False`) | v7 / v1.1 Score (post-CDE, `enable_cde_rescoring=True`) | Delta |
|-------------------|----------------------------------------------------|-----------------------------------------------------------|-------|
| `_cga_score` | **1.000** | **< 1.0** (exact TBD from re-scoring run) | Negative |
| OMISSION violations | 0 | ≥ 1 — `give_thrombolytic` REQUIRED by PE-MASSIVE-THROMBOLYSIS via CDE | +1 min |

| C3 forbidden_avoidance | 1.0 | Unchanged — agent correctly avoided thrombolysis | 0 |
| C6 conflict_surfacing | N/A (not in v6) | New sub-construct: CONFLICT violation count | New |

### Scoring Logic for ALTERNATIVE-PATH-OMISSION (v7 only)

Under the v7 SGSC `OR_REQUIRED` schema-encoding (workaround via
`alternative_branches` on pe.003/pe.004), when pe.002 fires (FORBIDDEN on
`give_systemic_thrombolysis`), the scoring engine checks whether **at least one**
of the alternative branch actions was performed:

```
ALTERNATIVE-PATH-OMISSION fires if:
  pe.002 FORBIDDEN active
  AND pe.003 (surgical_embolectomy) NOT performed
  AND pe.004 (catheter_directed_thrombolysis) NOT performed
  AND pe.005 (consult_interventional_radiology) NOT performed
```

In the SCN-012 trajectory, all three alternative actions were absent — producing
a maximum-severity ALTERNATIVE-PATH-OMISSION. This penalty is additive to the
CONFLICT violation and represents the clinical finding articulated by rater_015:
the agent neither treated the patient nor pursued any alternative route.

### Additivity Guarantee

Per the B-cde-rescoring design (Plan doc Part VI.5):

```
assert cde_cga_score <= legacy_cga_score   # for every episode
```

The SCN-012 post-CDE score satisfies this: the new violations can only decrease
the CGA score, never increase it. No episodes regress to higher scores.

## Draft App.~Z.1 Paragraph

The following paragraph is suitable for insertion into `paper/appendix_v18.tex`
at `\subsection{Issue Identification: Clinician-Surfaced Case}` (App.~Z.1),
bridging the v6 clinician validation finding to the v7 SGSC encoding:

---

> Pilot clinician validation of a massive pulmonary embolism scenario
> (hemodynamic instability, SBP 76 mmHg, saddle PE confirmed, relative
> contraindication to thrombolysis via recent surgery within three weeks)
> revealed a maximum scoring disagreement: the legacy CGA scorer assigned a
> perfect score of 1.0 despite the agent performing zero definitive
> treatment actions across twelve steps.  The root cause is structural:
> the runtime CPG engine evaluates only static mandatory and forbidden
> action lists per graph node, leaving the conditional rules block —
> which simultaneously declares systemic thrombolysis as REQUIRED
> (ESC 2019 Class~I, hemodynamic instability) and as FORBIDDEN (relative
> surgical contraindication) — entirely unevaluated at scoring time.
> The clinician adjudicator noted that even if thrombolysis were judged
> inappropriate, surgical embolectomy or catheter-directed thrombolysis
> should have been considered as mandatory alternatives; neither was attempted.
> The v7 SGSC corpus encodes this case systematically via three atoms
> (\texttt{pe.001}: thrombolysis REQUIRED; \texttt{pe.002}: thrombolysis
> FORBIDDEN; \texttt{pe.003/pe.004}: surgical or catheter-directed alternatives),
> and the counterfactual compiler generates an exclusion family
> (\texttt{pe\_thrombolysis\_recent\_surgery\_overlap}) reproducing the overlap
> condition at corpus generation time.  The v1.1 CDE patch couples the
> Constraint Derivation Engine into the scoring path: re-scoring the legacy
> trajectory under CDE coupling surfaces a CONFLICT violation (pe.001
> REQUIRED $\cap$ pe.002 FORBIDDEN), an OMISSION on the thrombolytic agent,
> and an ALTERNATIVE-PATH-OMISSION when none of the three alternative
> interventions are performed.  Pre- and post-patch headline numbers are
> reported transparently in Table~\ref{tab:cde_patch_delta}.
> This finding demonstrates the operational value of the audit-not-validation
> framing (\S\ref{sec:clinician_validation}): the clinician adjudication
> serves as the criterion-validity probe that surfaces catalogue-encoding
> gaps which the automated scorer cannot self-detect, and the v7 SGSC
> atom representation closes those gaps systematically rather than
> case-by-case.
