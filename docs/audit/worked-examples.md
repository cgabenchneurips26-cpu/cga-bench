ART / AgentEHR / HealthBench native bridges now produce genuinely
different BSR values after the 2026-04-23 silent-zero fix (commit
`a6c83884`): ART is at the Bayes floor (0.436) consistent with its
checklist-matching theory, AgentEHR sits just below the floor (F1-weighted
optimism), and HealthBench is above the floor (rubric scoring is
information-richer than bare checklist hits). MedAgentBench remains at
0.4839 because its bridge never had the silent-zero bug.

## Reproduce any report

```bash
PYTHONPATH=. python scripts/audit/evaluator_audit.py \
    --shim <shim_name> \
    --out-dir audit/reports \
    --top-k 5
```

Or run the entire table at once:

```bash
PYTHONPATH=. python scripts/audit/verify_audit_harness.py --fast
```
