CGA-Bench Croissant 전략
NeurIPS 2026 E&D 규정 요약
데이터셋을 제출하는 저자는 Croissant 기계 판독 가능 메타데이터와 함께 데이터셋을 제공해야 하며, 제출 마감 후 Croissant 파 NeurIPS일이 유효하지 않거나 데이터에 접근할 수 없는 경우 desk-rejection될 수 있습니다. 또한 RAI(Responsible AI) 메타데이터의 최소 세트를 반드시 제공해야 하며, 리뷰어가 이를 확인합니다. NeurIPS
CGA-Bench의 특수 상황
CGA-Bench는 전통적인 "이미지/텍스트 데이터셋"이 아니라 평가 인프라입니다. 구성 요소:
구성 요소형태Croissant 취급CPG graphs (25개)YAML filesFileSetScenarios (706개)JSON configsFileSetEpisodes (14,826개)JSON tracesRecordSetConstraints (1,049개)Engine-derivedFileSet (static export)Guideline Cards (25개)MarkdownFileSetEvaluation codePythonCroissant 범위 밖 (repo link)
FAQ에 따르면 복잡한 데이터셋의 경우 dataset-level 메타데이터와 리소스 설명(FileObject, FileSet)만 제공하고 RecordSet은 생략할 수 있습니다. NeurIPS
권장 호스팅: Hugging Face
Harvard Dataverse, Kaggle, Hugging Face, OpenML이 권장 플랫폼이며, 이들 플랫폼은 Croissant 파일을 자동 생성합니다. NeurIPS CGA-Bench에는 Hugging Face가 최적입니다 — JSON/YAML 파일 혼합 데이터셋 지원이 가장 좋고, 자동 Croissant 생성 + Parquet 변환을 제공합니다.

HuggingFace가 자동으로 Croissant JSON-LD를 생성하지만, episodes가 nested JSON이라 RecordSet을 수동으로 보강해야 합니다.
Phase 2: Croissant 파일 수동 보강 (Python API)
pythonimport mlcroissant as mlc

metadata = mlc.Metadata(
    name="CGA-Bench",
    description="Trace-level conformance auditing benchmark for clinical AI agents. "
                "Contains 25 CPG graphs, 706 scenarios, and 14,826 episode traces "
                "scored by 6 evaluators across 7 models.",
    url="https://huggingface.co/datasets/anonymous/cga-bench",
    license="cc-by-4.0",
    cite_as="@inproceedings{cgabench2026, ...}",
    
    # RAI metadata (mandatory for NeurIPS 2026)
    distribution=[
        mlc.FileObject(
            id="cpg-graphs",
            name="CPG Graph Library",
            content_url="cpg_graphs/",
            encoding_format="application/x-yaml",
            description="25 clinical practice guideline graphs (20 core + 5 held-out)"
        ),
        mlc.FileObject(
            id="episodes", 
            name="Episode Traces",
            content_url="episodes/",
            encoding_format="application/json",
            description="14,826 agent traces with multi-evaluator verdicts"
        ),
        mlc.FileObject(
            id="guideline-cards",
            name="Guideline Cards",
            content_url="guideline_cards/",
            encoding_format="text/markdown",
            description="Per-graph documentation of scope, constraints, and validation"
        ),
    ],
)
metadata.to_json("croissant.json")
Phase 3: RAI 메타데이터 추가 (필수)
RAI 메타데이터는 Croissant 파일에 포함되어야 하며, Croissant 필드에서 완전히 표현할 수 없는 정보는 논문의 관련 섹션을 명확히 가리켜야 합니다. NeurIPS
