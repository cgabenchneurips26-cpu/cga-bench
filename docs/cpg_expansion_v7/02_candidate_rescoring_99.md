## 점수화 근거 코멘트 (애매 케이스)

- **M1 애매**: 시간축이 "hours" 수준 (Myasthenic crisis, GBS, Bronchiolitis, HE, Rhabdomyolysis, Pheo, SVC, Hypercalcemia, DIC, SCC 등) → ≤60min action 3개 미달로 M1=0.
- **M3 부정**: 단일 consensus paper (Boyer-Shannon #78), 지역정부 (NSW #43), UK 네트워크 (BIMDG #68), IDSA 미발행 (Ludwig/PTA #93).
- **M4 애매**: Class I 미명시 + required_action < 10 guideline (Myxedema, Iron OD, AFE, Cord prolapse, Shoulder dystocia, Epistaxis)은 M4=0.
- **M6 애매**: 단일 pathway algorithm (ACLS Bradycardia, Epistaxis, CRAO, Shoulder dystocia, Iron OD)은 노드 < 7 → M6=0.
