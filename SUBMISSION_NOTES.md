# Submission Tree Notes

This directory is a stripped copy of the CGA-Bench development repository,
containing only the code, data, and evidence required to reproduce the
paper's quantitative claims. Generated by
`scripts/submission/prepare_submission.py`.

## Rename Requirement

The directory **must be named `cga_bench`** when deployed. All internal
imports use `from cga_bench.*` and will fail if the parent of the package
is not on `PYTHONPATH`.

```bash
mv cga_bench_submission cga_bench
# or:
ln -s cga_bench_submission cga_bench
cd cga_bench && PYTHONPATH=.. pytest tests/ -q
```

## Python Requirement

**Python 3.10 or newer.** The codebase uses PEP-604 union syntax
(`int | None`) and PEP-585 generics (`list[str]`) in module-level type
annotations. Python 3.8 / 3.9 will fail at import with
`TypeError: 'type' object is not subscriptable` or
`unsupported operand type(s) for |: 'type' and 'NoneType'`.

Tested on Python 3.11 / 3.12 / 3.13 + the pinned `requirements.lock`.

## Verifying the Submission

The bundled verifier exercises 11 critical files, 25 CPG graphs, the 3
entry-point scripts (syntax check), and 19 module imports:

```bash
python scripts/submission/prepare_submission.py \
    --source . --dest . --verify-only
```

Use a Python with `pydantic` and `pyyaml` available (see
`requirements.lock`).

## Test Suite Reproducibility

Running pytest against this submission tree yields the same pass/fail
profile as the development repo, with **2 known submission-only
exceptions**:

| Test | Reason |
|------|--------|
| `tests/test_audit/test_repair_distance.py::TestCorrelation::test_correlation_range` | Requires `results/full_706_v6_aliasfix_*/` trajectories (~8 GB of v6 episode logs) which are not shipped in the smoke-sample. Re-run the v6 episode corpus to populate. |
| `tests/test_mimic_iv_downstream.py::TestPhase5Schema::test_phase5_emits_required_per_cell_fields` | Writes `tex/auto_numbers_mimic_iv.tex`; the `tex/` directory is paper-bound and excluded by policy. Either restore `tex/auto_numbers_mimic_iv.tex` from the dev repo or skip this test in submission environments. |

The remaining test failures (currently 66 in both source and submission)
are pre-existing in the development repo and are unrelated to the
submission-stripping process; they are tracked in the source's test
backlog and do not affect the paper's quantitative claims.

```bash
# Reproduce the comparison
PYTHONPATH=.. python -m pytest tests/ -q --tb=no \
    --ignore=tests/test_e2e \
    --ignore=tests/test_clinician_validation \
    --ignore=tests/test_experiments
```

## Regenerating This Tree

```bash
# From the development cga_bench/ root:
python scripts/submission/prepare_submission.py \
    --source . \
    --dest ../cga_bench_submission \
    --keep-model-sample qwen4b
```

Notable script flags:
- `--keep-model-sample <name>` — restore one model's `results/full_706_v5/<name>/` outputs as a smoke-test sample (default `qwen4b`).
- `--dry-run` — print what would change without modifying anything.
- `--skip-copy` — re-run strip steps against an existing dest.
- `--verify-only` — just run the verifier (no copy or strip).
- `--skip-verify` — copy + strip, but skip final verification.

The script is idempotent: `dest` is wiped and rebuilt on every run.
